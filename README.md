# geo-character-video

扁平几何角色风格的动画视频工程，基于 Remotion（React → MP4）。

- 风格规范：[docs/style-bible.md](docs/style-bible.md)
- 制作流程：[CLAUDE.md](CLAUDE.md)

```bash
npm install
npm run studio                        # 预览
npm run render -- Demo out/demo.mp4   # 渲染样片
```

> 注意：Remotion 对 4 人以上的公司商用需要购买许可，详见 https://www.remotion.dev/license
